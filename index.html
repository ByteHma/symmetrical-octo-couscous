This page documents a personal Google Drive OAuth connection used by ByteHma with rclone to transfer and recover workstation backup files. The backup tools run locally—not on this website.

WEBSITE

Information only

01 / WORKFLOW

A straightforward path from local files to recovery.

This OAuth client gives the owner's rclone installation limited access to Google Drive. The public site does not handle that authorization or store files.

  1. 01

    Authorize locally

    The owner grants permission in Google's authorization flow. The resulting credentials remain in the local rclone configuration, not this repository.

  2. 02

    Transfer backup files

    Local backup tools prepare files for transfer. In the established DFKB workflow, the archive is encrypted before uploading to Drive.

  3. 03

    Verify and restore

    The owner can check stored files, download authorized backup objects, and validate restored data using local tools.

02 / DATA BOUNDARY

Limited access. No public accounts.

What is accessed

Files and associated metadata available through the authorized drive.file scope, as needed for backup uploads, checks, and restores.

What is not collected here

This static website has no Google sign-in, file upload interface, analytics code, or application database. GitHub may process basic hosting request information under its own policies.

Who it is for

Personal use by the account owner. There is no public backup service or subscription.

How to stop access

Google Account permissions can be reviewed or revoked at any time. Deleting backups is a separate action under the owner's control.
